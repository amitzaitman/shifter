# מאמן הילוכים

אפליקציית ווב לאייפון שמאמנת נהיגה ברכב ידני. היא מזהה מתי העברת הילוך, ונותנת פידבק בצבעים בלבד:

- **מסגרת המסך = תזמון:** ירוק בזמן, צהוב קצת מאוחר, אדום מאוחר מדי, סגול מוקדם מדי.
- **מילוי המסך = חלקות:** ירוק חלקה, צהוב טלטלה קלה, אדום קפיצה.
- **תוך כדי נסיעה:** מסגרת כחולה מהבהבת = להעביר עכשיו, סגולה = להוריד הילוך.

בלי חומרה נוספת. הסל"ד מזוהה מהמיקרופון, ההילוך מה-GPS, והחלקות ממד התאוצה של הטלפון.

## הפעלה באייפון

1. Settings ← Pages ← Source: `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`.
2. פותחים בספארי את `https://<user>.github.io/<repo>/`.
3. מאשרים מיקרופון, מיקום ותנועה. שמים את הטלפון במעמד.

Pages בחינם עובד רק על מאגר ציבורי. HTTPS חובה, בלעדיו ספארי חוסם את המיקרופון.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `engine.js` | המנוע: FFT, זיהוי סל"ד, למידת הילוכים, זיהוי העברה, ציונים, הדמיית נסיעה |
| `app.html` | הממשק (תבנית; המנוע מוזרק במקום `/*ENGINE*/`) |
| `build.py` | בונה את `index.html` (לאירוח) ואת `dist/shift-coach.html` (לדף ב-Claude) |
| `tests/test_engine.js` | בדיקות על צליל מנוע מדומה: `node tests/test_engine.js` |
| `tests/screenshot.py` | צילומי מסך של ההדגמה ב-Chrome headless (Playwright) |

אחרי כל שינוי ב-`engine.js` או ב-`app.html`: `python3 build.py`.
